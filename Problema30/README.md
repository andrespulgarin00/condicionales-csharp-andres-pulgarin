# Problema 30. Boletín de calificaciones

**Estructura elegida:** switch expression (letra y mensaje) + ternario + if

**Justificación:** Combina varias estructuras: rangos para la letra, valores exactos para el mensaje, ternario para aprobado/reprobado e `if` para la mención de honor.
